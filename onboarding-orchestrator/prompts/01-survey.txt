PARALLEL EXECUTION:
- Up to {WORKER_SLOTS} research agents will run SIMULTANEOUSLY
- Design tasks that are fully independent — no task should depend on the output
  of another task
- Aim for {WORKER_SLOTS} or more tasks to keep all worker slots busy
- If a topic is large, split it into independent sub-tasks rather than one big task
- Each agent only has access to data sources (Confluence, JIRA, code) — NOT to
  other agents' research outputs

CRITICAL REQUIREMENTS:
- Each task MUST be independent and parallelizable (no cross-task dependencies)
- Outputs MUST be distinct files in research/ directory
- Include specific data sources to investigate (not just "look at code")
- Focus on knowledge that's NOT in existing docs OR context that makes docs useful
- Agent field should list actual skill names (e.g., "confluence-access,codebase-overview")
